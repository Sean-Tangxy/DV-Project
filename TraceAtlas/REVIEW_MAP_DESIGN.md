# 文件面积地图与可展开文件索引

当前入口是 `review.html`。主图不再绘制数量圆点，文件地块本身承担面积和颜色编码。`index.html` 保留之前的 3D review。

## 地块编码

| 元素 | 含义 |
|---|---|
| 地块面积 | 最小保留面积 + 当前关联条目次数 × 全项目固定比例尺 |
| 地块颜色 | 当前条目数最多的主导层级 D0–D4／未知 |
| 灰色小地块 | 当前范围没有已定位的执行条目，保留位置和点击入口 |
| 粉色叉标 | 记录了失败或错误条目；不表示所有条目都失败 |
| 高亮描边 | 当前选中文件 |
| 细边界 | 文件区域的分割；岛外框与内部文件边界同色、同粗细 |

重复运行会重复计数。一个测试条目关联多个目标时，每个目标文件各自计入关联次数；不能把所有文件面积相加解释成去重用例总数。主导层级不删除其他层级，完整直方图和来源仍可在右侧查看。名称分类、源码推断和邻近版本候选不证明实际断言内容、执行覆盖或通过结果。

## 面积算法与可比较性

每个当前可见文件的目标面积为：

`A(file) = 90 + k × count(file)`

- `count` 为当前时段／轮次／运行／主题范围内的关联条目次数。
- 90 是世界坐标中的最小可点击保留面积。由于存在这个基础面积，100 次与 25 次文件的完整面积不会严格为四倍；**扣除基础面积后的增量**才与次数成正比。
- `k` 在加载完整数据时确定，从所有岛的空间容量与全量关联次数求共同可用上限。全部测试岛、项目岛、轮次共用同一个 `k`，不会每岛各自归一化。
- 岛的总面积是其可见文件目标面积之和；次数减少时岛会缩小。岛中心和总体排列固定，岛边界、文件边界和质心随数量改变。
- 所有零值文件仍有相同目标面积 90，使用灰色；不把未知或缺少执行证据当作通过。
- “等面积”模式给每个文件相同面积，便于检查结构；“次数面积”和“数量”模式都按当前次数分面积，后者另显示计数。

`review-area-layout.js` 实现带面积目标的幂图（加权 Voronoi）：

1. 为每个岛建立固定形状模板，以总目标面积缩放模板。
2. 从原有确定性螺旋点位生成岛内种子。
3. 对每对种子的加权距离不等式进行半平面裁切，构造凸多边形单元。
4. 通过共享边长度计算面积对权重的 Jacobian，以阻尼 Newton 迭代调整权重。
5. 检查每个单元的相对面积误差；不能达到 2% 阈值的岛，回退到面积精确的递归凸多边形 treemap。此时仍保留面积语义，但不声称它是幂图。
6. 使用单元的实际质心作为连线端点，使路径跟随地块变化。

当前全量 STS2 数据的一次验证中，所有岛均由幂图求解，最大相对面积误差约 0.5%。其他选择范围会单独验证并按需回退；这个结果不代表每个范围的误差都恰好相同。

缓存最多保留 30 组几何结果，键由可见文件、当前次数和面积模式构成。选中文件不会改变面积统计；选择新的轮次／运行会按新次数重建边界。相同范围再次查看复用缓存。

## 左侧文件索引

左侧改为 **文件类别 → 该类别的全部测试文件**，不再把用例名称主题当作文件分组计数。

- 每个测试文件只归入一个主类别岛；夹具单列，未命中规则归入未分类。
- 类别箭头展开／收起；顶部 ＋／− 展开／收起全部。
- 每个文件独占一行；长文件名省略显示，悬停查看完整路径、条目数及可见状态。
- 六列为该文件 D0–D4／未知的当前条目数，统一蓝色深浅；类别行统计是其子文件直方图之和。
- 列表包括数据中已收集的全部测试文件。当前范围无执行条目时仍保留行；若当前时点／会话没有可见文件证据，会在悬停中说明，不提前在地图伪造执行证据。
- 列表在主图中独立滚动，不拉长整个页面。已展开且处于列表可视范围的文件行用细线连接到对应地块；选中文件后只突出它的索引线。
- 点击行或地块都进入同一个文件详情。选择轮次、播放和范围刷选时同步更新统计；类别展开状态保留。

分组仍由文件名规则提供主主题线索，不能直接证明文件中的断言语义。规则在 `review-map-model.js` 的 `topics`。

## 连线与时间

默认用岛间汇总线减少拥挤；点击汇总线可查看实际文件对，点文件后展开直接引用目标。连线只使用当前记录中的条目关系，没有目标证据时不补造目标。

逐轮模式按该轮的执行条目分面积；累积模式按所选时段起点至当前轮的执行条目分面积。几何变化是数量变化，不是物理地理、代码行数、文件依赖跳数或覆盖率。

## 验证

- `verify-review-map.mjs`：证据条目完整性、文件对计数、跨岛统一面积尺度、零值保留、面积误差、单元质心与区域有效性、缓存一致性、人工极端比例样例。
- `verify-review-browser.mjs`：主图无圆点、面积随运行变化、文件类别展开到全部文件、无重复文件行、类别与子行计数一致、独立滚动、行／地块详情联动、轮次、播放和多尺寸布局。

主要文件：`review-area-layout.js` 处理面积求解；`review-map-view.js` 处理地块、文件索引与路径；`review-map-model.js` 处理分组与证据关联；`review-app.js` 处理轮次、播放和详情。

# TraceAtlas · 验证图谱

双击 index.html，用 Chrome 或 Edge 离线打开。全部数据和依赖都在本目录，不需要启动服务。

## 布局和操作

- 顶部：项目与记录、会话、检查、编辑、文件计数。
- 左上：检查演变，可展开任意会话。
- 左下：运行结果矩阵，点击单元格进入检查。
- 中央：同一地图里的目录群岛，可缩放、平移、点选文件及引用线。
- 右侧：选中记录、检查、文件或引用的证据。

页面不整体纵向滚动。内容在面板内滚动；? 打开当前图例，⤢ 放大，Esc 还原。完整说明见「系统阅读说明.md」或页面「阅读指南」。

## 数据与边界

保留全部 858 条已导出记录、17 个主/子会话及全部 858 条原始项。规则识别 41 项检查与 219 个可见文件路径。首页没有预选案例，不读取人工案例标签，不调用 LLM。

原导出 history_complete=false；没有完整历史版本、完整仓库文件清单和运行覆盖率。检查项不是用例数量，全部导出也不保证完整项目历史。

结果矩阵每行是同会话同目标的检查组，列号为该目标第几次可见尝试，不是共同时间。颜色表示结果，斜纹表示未知，浅色空格表示没有第 n 次记录。

文件群岛时间轴下方的蓝色短刻度表示发生了可识别测试的记录；它们是累计地图状态的观察节点，不代表测试通过。播放从当前全量状态开始时会自动回到第一个节点，再按记录顺序推进。

群岛引用从历史编辑片段提取：唯一声明类型的静态调用、构造调用、组件获取，以及明确路径字符串。每条都保存源记录和代码片段。这是局部词法近似，不是完整语义解析，也不是运行依赖。跨版本片段合并不代表同一时点的完整依赖。

文件群岛支持测试／项目分区、岛间底面连线、深度 3D 和数量模式。浏览器测试在岛屿布局及构成统计前排除，原始记录仍可查阅。项目柱高为直接关联测试的已知深度和，两套数据共用固定归一化上限；柱身色段按测试文件数显示深度占比。细则见「系统阅读说明.md」第 4 节。

底面连线的数字表示该有向目录对的去重文件引用对数。选中文件后展示逐条引用箭头。测试与项目文件在两侧稳定排布；几何距离不是依赖证据，引用也不是动态覆盖。

## 文件与复现

| 文件 | 用途 |
|---|---|
| index.html、style.css、redesign.css | 页面与布局 |
| app.js、views.js、map-view.js、map-3d.js | 交互、矩阵、地图与 WebGL 柱体 |
| model.js | 命令、检查、文件和条件解析 |
| atlas.js | 可追溯片段引用和群岛布局 |
| dataset.js | 全部规范化和原始数据 |
| prepare.mjs | 从同结构导出包重新生成数据 |
| verify.mjs、validation.json | 规则、引用和浏览器验证 |
| overview.png、interaction.png | 最新截图 |

重新生成：node v1/prepare.mjs。

同结构数据导入：node v1/prepare.mjs "数据包目录" "原项目目录名"。不同工具需要新增对应解析器，不按记录号预设图形。

验证：node v1/verify.mjs。浏览器交互验证：node v1/verify.mjs --browser，使用独立临时配置，只验证页面和规则，不重新运行 Unity。


## 新数据集与使用

双击 index.html，在顶部选择 STS2 Agent；或直接打开 index.html?dataset=sts2。新增 dataset-sts2.js 从同目录 STS2_Agent_Dataset(1).zip 导入，全量保留 2,234 条记录、17 个会话及 199 个历史文件；末端当前可见 196 个文件。193 个引用对来自标明版本的 Git 快照，不回填到快照以前。

地图上方切换「结构／深度 3D／数量」。3D 使用固定正交相机和 WebGL 深度缓冲，保留缩放、平移和点选。禁用 WebGL 时会标注「SVG 预览」。点项目文件可查看测试数、深度和及深度构成，点测试文件可查源码规则和关联项目文件。

prepare-sts2.py 仅解析压缩包 JSON 与数据赋值，不运行包里的分析代码。重新导入使用 python v1/prepare-sts2.py。深度分类是通用源码规则，未沿用包里的项目专用人工案例标签。验证使用 node v1/verify.mjs（在 v1 的上一级目录运行）。

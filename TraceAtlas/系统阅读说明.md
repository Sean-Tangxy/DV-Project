# TraceAtlas 使用与图例

## 1. 布局

顶部项目名旁依次为记录、会话、检查、编辑和文件计数。检查数不是用例数，文件数不是仓库全部文件。

左上检查演变、左下结果矩阵、中央文件群岛、右侧证据详情。? 打开当前说明，⤢ 放大面板，Esc 还原。内容在面板内滚动，整页不纵向滚动。

## 2. 检查演变

每行一个会话，S01 等是页面编号。点会话名展开为编辑和检查类型轨道，再点轨道名返回全项目。

默认 0%—100% 表示会话内记录顺序，不是耗时或完成度；不同会话横向对齐不表示同时发生。切换「记录时间」使用缓存锚点，不是校准后的执行起止时间。

| 标记 | 含义 |
|---|---|
| 绿色勾 | 检查在识别范围内通过 |
| 红色叉 | 内部检查或脚本失败 |
| 橙色叹号 | 启动受阻 |
| 蓝色圆 | 记录当时仍在运行 |
| 棕色圆 | 通过和失败混合 |
| 空心灰圆 | 结果未知 |
| 实心灰圆 | 明确跳过 |
| 紫色短线 | 文件编辑 |
| 小灰点 | 其他公开记录 |
| 虚线 | 同会话同目标的顺序，不表示因果 |
| 深色外圈 | 当前 B |
| 蓝色外圈 | 固定参照 A |

悬停可看完整名称和来源。S07 #277 是源记录号，不是第 277 次测试。主图保留简短图例，完整状态在 ? 中查看。

## 3. 运行结果矩阵

每行是同会话同目标的一组检查。第 1、2、3 列表示该行目标第几次可见尝试，不是共同时间。

- 彩色格：一次已观察检查，颜色对应结果。
- 斜纹格：观察到检查，但结果未知。
- 浅色空格：没有第 n 次记录，不能当作跳过。
- 深色边框：当前 B；白色小点：固定 A。

点格子后，右侧显示真实依据；下方可展开「条件对照」和「逐项观测」。设为 A 后，点任意其他运行作为 B。

条件指纹每列一次运行，每行一个维度。前四行同色只表示保存的值相同，斜纹表示未知；结果行使用全局状态色。未知版本不能比较为相同。参数相同也不证明输入、断言和环境全部相同。

逐项观测只展示脚本实际输出的条目；小色格是结果，? 表示未见同名条目。它不是独立用例计数，未见也不表示删除或未执行。

## 4. 文件群岛：测试、关联、深度与数量

顶部可切换 sszx_vs_zz 与 STS2 Agent。两套数据分别显示，保留全部导出记录。STS2 的 199 个文件包括历史出现过又移除的文件，所以当前时间可见数量可能少于 199。

左侧是测试文件，右侧是项目文件；一个六边形是一个文件，目录聚成岛。测试角色优先采用导入数据的标记，否则用测试目录／文件命名规则识别。普通项目文件即使命中引擎关键词，也不因此被当作测试文件。目录位置用于稳定排布，不解释为精确依赖距离。

| 控件／编码 | 读法 |
| --- | --- |
| 结构 | 二维文件地图；测试源码按层级着色，项目文件用浅灰蓝 |
| 深度 3D | 测试柱高 = 当前最新可见源码的可识别层级；项目柱高 = 去重关联测试的已知深度和，按两套数据共用的固定上限线性归一化 |
| 数量 | 测试文件数字 = 直接关联项目文件数；项目文件数字 = 不同关联测试文件数 |
| 项目柱身色段 | 从下到上依次为 D0—D4 和未知。每段高度占比 = 该级测试文件数 / 关联测试文件总数 |
| 底部构成条带 | 默认看所有测试文件的层级分布；选项目文件后看其关联测试分布 |
| 岛间底面连线 | 标签显示同一有向目录对的去重文件引用对数，点线可核查证据 |
| 柱顶箭头 | 选中文件后显示其逐条直接引用，3D 中由来源柱顶向上出发、落到目标柱顶 |
| 紫色边框 | 当前截面之前可见编辑 |
| 蓝紫粗边／黄色边 | 当前检查的明确目标／诊断位置 |
| 深色粗边 | 当前选中文件 |

深度用 D0 源码／静态、D1 本地逻辑、D2 替身／进程、D3 引擎、D4 界面区分。该规则读取源码中的断言和设置组合，右侧提供命中的原句。只存在文件名、源码不完整、环境缺失时允许未知。D4 也可能是开发仪表盘的界面测试；它不自动代表游戏客户端。

项目柱高累加已知深度，D0 贡献 0，未知只计入柱身的深度构成。固定上限按两套数据的已观察文件及其最深证据计算，切换时间或会话不会改变标尺。没有可见关联的文件仍显示底座。右侧详情展示深度和、关联数量及各层级计数，供核查柱高与色段。

地图布局和统计排除浏览器测试文件，剩余文件按目录重新紧凑排列。原始记录保留这些测试。WebGL 模式支持缩放、平移和点选，浏览器禁用 WebGL 时用标明的 SVG 预览。

测试数量的单位严格区分：地图统计不同测试文件，不是断言数、参数化展开用例数或运行次数。同一测试文件多次引用、多次运行不增加文件数；运行次数和结果仍看左侧矩阵与记录。

时间轴以事件为最细单位，默认使用与地图有关的编辑、检查、提及和末尾记录。拖动或播放时，地图、矩阵当前选择和右侧证据联动。选中文件或引用线后保留对象，并按时间筛选证据。Git 快照的源码分类和引用仅在快照时刻后出现，不向早期补造边。当前 STS2 包的 193 条引用来自一个 Git 快照，所以早期可能有测试文件却没有可见快照连线，这是证据限制。

测试文件→项目文件采用可查证的源码直接引用。STS2 导入包保留 import／调用片段、行号及版本，sszx 使用历史片段的局部词法提取。缺少引用不解释为没有测试；存在引用不等于执行覆盖、断言覆盖或通过。

滚轮缩放、拖动平移、「适配」返回全景。点文件看数量、层级来源和关联文件；点线束看其中每对文件的引用原文。顶部 ⤢ 可放大地图。

## 5. 证据详情

点检查或矩阵格可读状态、规则编号、真实依据和完整输入输出。外层 exit 0 不会覆盖内部失败。

点文件显示关联记录；点引用线显示来源文件、目标文件、符号、代码片段和源记录号。点记录号可回查完整原文。

默认不推荐案例，不预先标问题。你可以从任何会话、单元格或文件开始，先看图形关系和变化，再比较条件、追溯文件，最后核对出处。
